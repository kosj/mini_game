# 🎮 mini_game

친구들과 함께 즐기는 웹 미니게임 모음입니다. 현재 **사다리 타기**와 **가위 바위 보**가 포함되어 있고, 앞으로 게임을 계속 추가할 수 있는 구조입니다.

## 🪜 사다리 타기

1. **방 만들기** — 사다리의 목적(예: "오늘 커피 사는 사람 정하기"), 인원 수, 결과 항목을 입력합니다.
2. **초대** — 생성된 초대 링크를 친구들에게 공유합니다.
3. **위치 선택** — 각자 링크로 들어와 이름을 입력하고 원하는 위치를 선택합니다. (시작 전에는 다른 빈 칸으로 이동 가능)
4. **자동 시작** — 모든 위치가 선택되면 3초 카운트다운 후 모두의 화면에서 동시에 사다리 애니메이션이 실행되고 결과가 공개됩니다.

## ✌️ 가위 바위 보

1. **방 만들기** — 게임의 목적, 뽑는 방식(진 사람 뽑기 / 이긴 사람 뽑기), 인원 수를 입력합니다.
2. **초대** — 초대 링크를 공유하고, 각자 이름을 입력해 참가합니다. 정원이 차면 자동 시작됩니다.
3. **라운드 진행** — 모두 몰래 가위/바위/보를 내면 "가위~ 바위~ 보!" 연출과 함께 동시에 공개됩니다.
   - 무승부(모두 같거나 셋 다 나옴)면 자동으로 재대결
   - **진 사람 뽑기**: 이긴 사람은 통과하고 진 사람끼리 계속 → 마지막 한 명이 당첨
   - **이긴 사람 뽑기**: 진 사람은 탈락하고 이긴 사람끼리 계속 → 마지막 한 명이 승자

## 공통

- 실시간 동기화는 SSE(Server-Sent Events)로 처리합니다.
- 방은 서버 메모리에 저장되며 24시간 뒤 자동 만료됩니다.

## 실행

외부 의존성이 없어 Node.js(18+)만 있으면 됩니다.

```bash
npm start        # 또는 node server.js
# http://localhost:3000
```

포트는 `PORT` 환경변수로 변경할 수 있습니다.

## 배포

실시간 서버(SSE)가 필요하므로 정적 호스팅(GitHub Pages)이 아닌 Node 실행이 가능한 곳에 배포하세요. 어디든 `node server.js` 하나로 동작합니다.

- **Render / Railway / Koyeb / Fly.io**: 레포 연결 후 시작 명령을 `node server.js`로 설정 (Dockerfile 포함되어 있어 Docker 기반 배포도 가능)
- **직접 서버**: `PORT=80 node server.js`

> 여러 인스턴스로 스케일아웃하면 방 상태가 인스턴스별 메모리에 있어 공유되지 않으니 단일 인스턴스로 운영하세요.

## 프로젝트 구조

```
server.js            # 정적 서빙 + 사다리 API + SSE (의존성 없음)
public/
  index.html         # 미니게임 허브 (게임 목록)
  ladder/            # 사다리 타기 프론트엔드
    index.html
    app.js
    style.css
```

새 미니게임은 `public/<게임이름>/`에 프론트엔드를 추가하고, 서버 로직이 필요하면 `server.js`에 `/api/<게임이름>/...` 라우트를 추가하는 방식으로 확장합니다.
